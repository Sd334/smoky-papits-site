# Smoky Papits — учебный SEO-проект

Статический учебный сайт бара на GitHub Pages: https://sd334.github.io/smoky-papits-site/.
Адрес, телефон, цены, события и условия в макете — демонстрационные данные. Сайт не принимает бронирования. Перед реальной публикацией сведения надо заменить подтверждёнными данными бизнеса.

## Как учиться на проекте

Откройте `seo-practice.html` или ссылку «SEO-практика» внизу любой страницы.

1. Разберите карту шести страниц и задачи посетителей.
2. Составьте title главной. Проверка покажет конкретно, чего не хватает: тип заведения, бренд или город.
3. Запустите проверку HTML и Sitemap. Результаты не подтверждают индексацию или рост трафика.
4. Выполните изменения в коде и оформите честный кейс до/после.
5. Запишите выводы в тетрадь. Она сохраняется только в текущем браузере; для другого устройства используйте экспорт и импорт JSON. Сохранение в аккаунте есть в вашей отдельной школе: https://seo-practice-alex-x20.kibardin-vanb.chatgpt.site/.

Учебная страница помечена `noindex,follow` и исключена из Sitemap; основные страницы бара доступны для обхода.

## Запуск и проверка

Сайт не требует установки зависимостей или сборки.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
python3 scripts/check_site.py
node --check js/script.js
node --check js/training.js
```

Откройте http://127.0.0.1:8000/. Проверка на учебной странице требует HTTP-сервера; при открытии файлов двойным щелчком браузер может блокировать чтение соседних страниц.

## Важные детали SEO

- Canonical и Sitemap используют настоящий адрес GitHub Pages. После переезда на собственный домен их нужно согласованно обновить.
- `robots.txt` в папке `/smoky-papits-site/` не управляет обходом GitHub Pages: поисковые роботы читают файл в корне домена `https://sd334.github.io/robots.txt`. Репозиторий проекта не управляет этим корнем; локальный файл — поясняющий пример. Sitemap можно отправить в Вебмастер или Search Console после подтверждения прав.
- Title и description должны описывать страницы. Числа 60/160 символов не являются жёсткими правилами поисковых систем.
- Из демонстрационного макета удалена разметка реального BarOrPub с непроверенными сведениями. Оставлена разметка WebSite с явным учебным описанием.
- На форме нет отправки на сервер. JavaScript проверяет учебные поля, не записывает личные данные и явно сообщает, что бронирование не создано. При выключенном JavaScript отправка отключена.
